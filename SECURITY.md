# Security Policy

## Supported versions

Security fixes are provided for the latest `0.1.x` release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include an inflow API Key in any report.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/nnquant/inflow-publisher/security/advisories/new

Include the affected release, command, expected behavior, actual behavior, and a minimal reproduction with all credentials and private URLs removed.

If an API Key may have been exposed, revoke it immediately in inflow and create a replacement key.
